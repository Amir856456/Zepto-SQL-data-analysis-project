# Zepto SQL Data Analysis

## About

This project is about analyzing Zepto product data using Excel, PostgreSQL and SQL.

The main goal is to clean the data, explore it and find useful business insights.

## Tools Used

- Excel
- PostgreSQL
- SQL
- pgAdmin

## Excel

Excel was used for:

- Checking the raw data
- Basic data cleaning
- Finding missing values
- Checking duplicates
- Sorting and filtering data
- Preparing the data for SQL

After cleaning, the data was imported into PostgreSQL.

## SQL Analysis

SQL was used to analyze:

- Product categories
- Product prices
- Discounts
- Stock availability
- Product weight
- Inventory
- Estimated revenue

Some of the questions answered were:

1. What are the top 10 products based on discount?
2. Which high-price products are out of stock?
3. What is the estimated revenue for each category?
4. Which products have MRP above ₹500 and discount below 10%?
5. Which categories have the highest average discount?
6. What is the price per gram of products?
7. How can products be grouped based on weight?
8. What is the total inventory weight for each category?

## Project Flow

Excel → PostgreSQL → SQL Analysis → Insights
